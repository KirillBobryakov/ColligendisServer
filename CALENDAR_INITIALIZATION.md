# Инициализация календарей в Colligendis Server

## Обзор

Система автоматической инициализации календарей позволяет сохранять в базу данных различные календарные системы, используемые в нумизматике. Поддерживается более 190 различных календарей, включая древние, современные и региональные системы.

## Компоненты

### 1. CalendarInitializationService
Сервис для массового сохранения календарей в базу данных.

**Основные методы:**
- `initializeAllCalendars()` - инициализирует все доступные календари (192 календаря)
- `initializeBasicCalendars()` - инициализирует только основные календари (14 календарей)
- `areCalendarsInitialized()` - проверяет, инициализированы ли календари
- `getCalendarCount()` - возвращает количество сохраненных календарей

### 2. CalendarRestController
REST API для работы с календарями.

**Endpoints:**
- `GET /api/calendars` - получить все календари
- `GET /api/calendars/{uuid}` - получить календарь по ID
- `GET /api/calendars/by-code/{code}` - получить календарь по коду
- `POST /api/calendars` - создать новый календарь
- `PUT /api/calendars/{uuid}` - обновить календарь
- `DELETE /api/calendars/{uuid}` - удалить календарь
- `POST /api/calendars/initialize/all` - инициализировать все календари
- `POST /api/calendars/initialize/basic` - инициализировать основные календари
- `GET /api/calendars/status` - получить статус инициализации

## Автоматическая инициализация

При запуске приложения автоматически проверяется, инициализированы ли календари. Если нет - происходит инициализация основных календарей:

- Gregorian/Julian
- Islamic (Hijri)
- Iranian - Persian
- Hebrew
- Ethiopian
- Thai
- Japanese - Heisei era
- Japanese - Reiwa era
- Chinese - Qianlong era
- Korean - Joseon era
- Vikram Samvat
- Shaka era
- Unknown

## Использование

### Через REST API

```bash
# Проверить статус
curl http://localhost:8080/api/calendars/status

# Инициализировать основные календари
curl -X POST http://localhost:8080/api/calendars/initialize/basic

# Инициализировать все календари
curl -X POST http://localhost:8080/api/calendars/initialize/all

# Получить все календари
curl http://localhost:8080/api/calendars

# Получить календарь по коду
curl http://localhost:8080/api/calendars/by-code/gregorien
```

### Программно

```java
@Autowired
private CalendarInitializationService calendarInitializationService;

// Инициализировать все календари
List<Calendar> calendars = calendarInitializationService.initializeAllCalendars();

// Проверить статус
boolean initialized = calendarInitializationService.areCalendarsInitialized();
long count = calendarInitializationService.getCalendarCount();
```

## Логирование

Все операции инициализации логируются через `DebugUtil` с соответствующими уровнями:
- INFO - успешные операции
- WARNING - предупреждения (например, обновление существующих записей)
- ERROR - ошибки при сохранении

## Структура базы данных

Календари сохраняются как узлы Neo4j с меткой `CALENDAR` и следующими свойствами:
- `code` - уникальный код календаря
- `name` - человекочитаемое название
- `toGregorianShift` - сдвиг относительно григорианского календаря в годах

## Сдвиги календарей (toGregorianShift)

Система автоматически инициализирует сдвиги для основных календарей:

### Основные календари с известными сдвигами:
- **Gregorian/Julian**: 0 (базовый календарь)
- **Islamic (Hijri)**: 622 (начинается в 622 году н.э.)
- **Persian**: 622 (совпадает с исламским)
- **Hebrew**: -3761 (начинается в 3761 году до н.э.)
- **Japanese Heisei**: 1989 (1989-2019)
- **Japanese Reiwa**: 2019 (2019-настоящее время)
- **Korean Joseon**: 1392 (1392-1910)
- **Vikram Samvat**: -57 (57 год до н.э.)
- **Shaka era**: 78 (78 год н.э.)
- **Armenian**: 551 (551 год н.э.)
- **Buddhist (Chulasakarat)**: -543 (543 год до н.э.)

### Значения сдвигов:
- **Положительные числа**: календарь начинается в указанном году н.э.
- **Отрицательные числа**: календарь начинается в указанном году до н.э.
- **null**: сдвиг неизвестен или не применим
